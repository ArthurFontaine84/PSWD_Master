# PSWD Master

**Vos mots de passe, chez vous.**

> 📖 **[Cliquez ici pour accéder au guide d'utilisation](docs/GUIDE.md)**

PSWD Master retient tous vos mots de passe dans un **coffre chiffré**. Vous n'avez plus qu'un seul mot de passe à connaître : le mot de passe maître, qui ouvre le coffre.

## Pourquoi PSWD Master ?

La plupart des gestionnaires de mots de passe gardent vos données sur les serveurs d'une entreprise. PSWD Master a été créé pour ne dépendre de personne :

- **Vos données restent chez vous** : sur vos appareils et, si vous le souhaitez, sur votre propre serveur. Aucun compte à créer, aucun abonnement.
- **Tout est chiffré sur votre appareil** : sans le mot de passe maître, un coffre est illisible, y compris pour votre serveur.
- **Fonctionne sans Internet.**
- **Synchronisation facultative** : avec un serveur installé à la maison, vos coffres vous suivent sur tous vos appareils, et vous pouvez en partager avec votre famille.

## Deux façons de l'utiliser

| | **Sur un seul appareil** | **Avec votre serveur maison** |
|---|---|---|
| Pour qui | Une personne, un ordinateur ou un téléphone | Plusieurs appareils, ou toute la famille |
| À installer | L'application, c'est tout | L'application, et le serveur sur un PC toujours allumé |
| Vos coffres | Sur l'appareil, sauvegardés dans un fichier | Les mêmes sur tous vos appareils, à jour en quelques secondes |
| Partage | — | Coffres communs (Wi-Fi de la maison, abonnements…) |

On peut commencer seul et ajouter le serveur plus tard : les coffres existants le rejoignent.

## Disponible sur

Windows, Linux, macOS et Android. iOS

## Avant de commencer

- **Mot de passe maître et clé de récupération perdus = coffre perdu.** Personne ne peut l'ouvrir, pas même le serveur. Notez la clé de récupération sur papier dès la création du coffre.
- **Faites des sauvegardes** de vos coffres sur une clé USB ou autre support externe pour prévenir en cas de panne ou perte de l'appareil.
